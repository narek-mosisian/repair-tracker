
# Repair Tracker

An open-source web application for managing repair and service orders in small businesses.

## Overview

Repair Tracker helps small businesses organize customer orders and allows customers to track repair progress online.

Designed for repair shops, tailors, bicycle workshops, and other service providers.

> Project status: Early development. Not ready for production use.

## Planned Features

- Business dashboard
- Create, update, and manage orders
- Public order tracking via secure links
- User authentication
- PostgreSQL persistence
- Docker-based deployment

## Tech Stack

- Next.js, React, TypeScript
- Tailwind CSS
- PostgreSQL
- Prisma
- Docker
- GitHub Actions

## Getting Started

Requirements:
- Node.js
- npm

Install dependencies:

    npm install

Start the development server:

    npm run dev

Open http://localhost:3000.
